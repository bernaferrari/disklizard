# README screenshots

These are unedited captures of the browser demo, using sample data rather than
personal filesystem contents.

To refresh them:

1. Start the browser demo: `bun run --cwd packages/app dev`.
2. Open `/?fixture=demo&theme=light` at a 1440 × 1120 viewport, device scale
   factor 2, with reduced motion.
3. Scan **Macintosh HD** and wait for the completed map. Move the pointer off
   the map, then capture `storage-map.png`.
4. Switch to **Tiles** and capture `storage-tiles.png`.
5. Open **Clean up**, add the `web-dashboard` and `legacy-admin` build folders
   to the selection, and capture `cleanup-review.png` without confirming a
   Trash operation.
6. Repeat with `theme=dark` and save the same views with a `-dark` suffix.
   The main README shows them automatically to readers using a dark theme.

Wait for fonts and the requested view to finish rendering before each capture.
